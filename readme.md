# UUJCOM431 - Laravel Application

This repository contains a Laravel-based web application created as part of Ulster University (UUJ) coursework.

## What is included?
- Laravel PHP application structure
- Models, routes, configuration, and tests
- Front-end assets and public entrypoint

## Getting started
Install dependencies and run the app locally:

```bash
composer install
php artisan serve
```

## Notes
- This project uses a typical Laravel layout with configuration files and test coverage.
- It is intended for coursework review and local development experiments.
